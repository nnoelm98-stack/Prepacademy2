Solving Quadratic Equations
Master the three methods for solving quadratic equations — factoring, the quadratic formula, and completing the square — and learn when to use each one for maximum speed on the SAT.
14 min read3 practice questions+20 pts on completion
Three methods — choose the fastest one
Every quadratic equation can be solved by any of these three methods. The SAT rewards students who pick the right method for the problem — the wrong method can waste 2–3 minutes.
Method 1 — Factoring
Use when: the equation looks factorable (integer coefficients, small numbers). Always try this first — it's fastest.
1. Set equation = 0
2. Factor into (x + p)(x + q) = 0
3. Set each factor = 0 and solve
x² + 5x + 6 = 0
(x + 2)(x + 3) = 0
x = −2 or x = −3
Method 2 — Quadratic Formula
Use when: the equation doesn't factor easily, or you need exact answers with radicals.
Set ax² + bx + c = 0
Then apply the formula →
Always works. Never fails.
Method 3 — Square Root Method
Use when: there's no linear term (no x, only x²). Isolate x² and take the square root of both sides.
x² = k → x = ±√k
4x² − 36 = 0
4x² = 36
x² = 9
x = ±3
SAT speed rule
Try factoring first (5 sec). If it doesn't factor in 10 seconds, use the quadratic formula. Don't waste time trying to force a factorization.
Factoring → fastest when it works
Quadratic formula → always reliable
Square root → for x² = k only
The Quadratic Formula — and the discriminant
x = (−b ± √(b² − 4ac)) / 2a
for ax² + bx + c = 0, where a ≠ 0
The expression under the square root, b² − 4ac, is called the discriminant. It tells you how many real solutions the equation has — without fully solving it.
b² − 4ac > 0
Two distinct real solutions
Parabola crosses x-axis twice
x² − 5x + 4 = 0 → D = 9 > 0 → x = 1 or x = 4
b² − 4ac = 0
One repeated real solution
Parabola touches x-axis at vertex
x² − 6x + 9 = 0 → D = 0 → x = 3 only
b² − 4ac < 0
No real solutions
Parabola doesn't cross x-axis
x² + x + 1 = 0 → D = −3 < 0 → no real solutions
Worked example — quadratic formula
Solve: 2x² − 3x − 5 = 0

a = 2, b = −3, c = −5
Discriminant: (−3)² − 4(2)(−5) = 9 + 40 = 49
x = (3 ± √49) / 4 = (3 ± 7) / 4
x = (3 + 7)/4 = 10/4 = 5/2  OR  x = (3 − 7)/4 = −4/4 = −1
Check: 2(25/4) − 3(5/2) − 5 = 25/2 − 15/2 − 10/2 = 0 ✓
SAT strategy tips
Always set equation to zero first
Before factoring or using the formula, make sure the equation is in the form ax² + bx + c = 0. If the equation has terms on both sides, move everything to one side before doing anything else.
Use the discriminant for "how many solutions" questions
If the SAT asks how many real solutions an equation has — compute b² − 4ac. You don't need to fully solve it. Positive → 2 solutions. Zero → 1 solution. Negative → 0 solutions.
Factoring: find two numbers that multiply to c and add to b
For x² + bx + c = 0: find p and q such that p × q = c and p + q = b. Then factor as (x + p)(x + q) = 0. This is faster to execute than the formula for clean integer roots.
Sum and product of roots
For ax² + bx + c = 0 with roots r₁ and r₂: sum of roots = −b/a and product of roots = c/a. The SAT occasionally asks for the sum or product of roots without asking you to find each root.

Problem
The equation x² + kx + 16 = 0 has exactly one real solution.
Exactly one real solution means the discriminant = 0. Set b² − 4ac = 0 and solve for k. Remember k can be positive or negative.
