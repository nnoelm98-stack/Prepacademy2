Parabolas & Vertex Form
Learn to read the vertex, axis of symmetry, direction, and intercepts of a parabola from its equation — in both standard and vertex form — without graphing.
13 min read3 practice questions+20 pts on completion
Two forms of a quadratic — what each reveals
The same parabola can be written in different forms. Each form makes certain features immediately visible. The SAT will switch between forms and ask you to identify key features — know what each form tells you at a glance.
Standard Form
f(x) = ax² + bx + c
Best for reading the y-intercept (c) and the direction (sign of a).
y-intercept: x = 0 → y = c
Axis of symmetry: x = −b/(2a)
Vertex x: −b/(2a), then substitute for y
Opens up: a > 0 · Opens down: a < 0
Vertex Form
f(x) = a(x − h)² + k
Best for reading the vertex and axis of symmetry directly.
Vertex: (h, k) — read directly
Axis of symmetry: x = h
Min/Max value: k (minimum if a>0, maximum if a<0)
Opens up: a > 0 · Opens down: a < 0
Critical trap — vertex form sign
In f(x) = a(x − h)² + k, the vertex is at x = h — NOT x = −h.

f(x) = 2(x − 3)² + 5 → vertex at (3, 5) ✓
f(x) = 2(x + 3)² + 5 = 2(x − (−3))² + 5 → vertex at (−3, 5) ✓

When you see (x + h), rewrite as (x − (−h)) to identify the vertex correctly.

Converting between forms
The SAT may give an equation in one form and ask about a feature best read from the other. Knowing how to convert quickly is essential.
Worked example — standard to vertex form
Convert f(x) = x² − 6x + 5 to vertex form.

Step 1: Find vertex x — axis of symmetry: x = −(−6)/(2·1) = 3
Step 2: Find vertex y — f(3) = 9 − 18 + 5 = −4
Step 3: Vertex form: f(x) = (x − 3)² − 4
Verify: (x−3)² − 4 = x² − 6x + 9 − 4 = x² − 6x + 5 ✓

Vertex: (3, −4) · Axis of symmetry: x = 3 · Minimum value: −4
SAT strategy tips
Vertex form → read vertex instantly
If the SAT gives vertex form f(x) = a(x−h)²+k, the vertex is (h, k). Don't calculate — just read it. Watch the sign: (x−3)² gives h = 3, but (x+3)² gives h = −3.
Minimum value ≠ vertex x-coordinate
The minimum (or maximum) value of the function is k — the y-coordinate of the vertex. The SAT frequently asks "what is the minimum value of f?" — the answer is k, not h.
Axis of symmetry from standard form
x = −b/(2a) is fast and always works. For f(x) = 2x²−12x+7: axis = −(−12)/(2·2) = 12/4 = 3. The vertex is at x = 3, and the minimum value is f(3).
Number of x-intercepts from the vertex
If the parabola opens up (a>0) and vertex is above x-axis (k>0) → no x-intercepts. If vertex is on x-axis (k=0) → one. If below (k<0) → two. Flip logic for a<0.
Practice questions
Problem
A parabola is defined by:
f(x) = −2(x + 3)² + 8
Rewrite (x + 3) as (x − (−3)) to identify h = −3. The vertex is (h, k) = (−3, 8). Since a = −2 < 0, the parabola opens down — so k = 8 is a maximum.

Problem
A parabola in standard form:
f(x) = x² − 8x + 7
Find the axis of symmetry using x = −b/(2a) = −(−8)/(2·1) = 4. Then substitute x = 4 to find the vertex y-value. The vertex is the minimum since a = 1 > 0.

Problem
A ball is thrown upward. Its height h in feet after t seconds is modeled by:
h(t) = −16t² + 64t + 5
The maximum height occurs at the vertex. Find t at the vertex using t = −b/(2a) = −64/(2·(−16)). Then substitute to find the maximum height h.
Question 3 · Real-World Parabola
What is the maximum height the ball reaches?
A64 feet
B69 feet
C5 feet
D128 feet
Correct! 69 feet
Vertex at t = −64/(2·(−16)) = −64/(−32) = 2 seconds
h(2) = −16(4) + 64(2) + 5
= −64 + 128 + 5
= 69 feet ✓

Option C (5 feet) is the initial height h(0) — not the maximum.
Option A (64) is just the coefficient of t — not a height.
Option D overcounts.
Not quite. Maximum height is the y-coordinate of the vertex. Find t at vertex: t = −b/(2a) = −64/(2×(−16)) = 2. Then compute h(2).
h(2) = −16(4)+64(2)+5 = −64+128+5 = 69 feet
