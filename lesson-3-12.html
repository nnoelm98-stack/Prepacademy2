Polynomials
Learn to add, subtract, multiply, and factor polynomial expressions — and master the Remainder Theorem and Factor Theorem, two powerful shortcuts the SAT uses repeatedly.
13 min read3 practice questions+20 pts on completion
Polynomial basics
A polynomial is a sum of terms, each of the form axⁿ where n is a non-negative integer. The degree is the highest power of x in the expression.
TermDefinitionExample
DegreeHighest exponent in the polynomial3x⁴ − 2x² + 5 has degree 4
Leading coefficientCoefficient of the highest-degree term3x⁴ − 2x² + 5: leading coeff = 3
Like termsTerms with the same variable and exponent4x² and −7x² are like terms
Roots / zerosValues of x where the polynomial equals zeroIf p(2) = 0, then x = 2 is a root
FactorAn expression that divides the polynomial evenlyIf x = 2 is a root, then (x − 2) is a factor
Operations on polynomials
Adding & Subtracting
Combine like terms — same degree, same variable. Watch signs when subtracting: distribute the negative to every term in the second polynomial.
(3x² + 2x − 1) + (x² − 5x + 4)
= 4x² − 3x + 3

(3x² + 2x − 1) − (x² − 5x + 4)
= 2x² + 7x − 5
Multiplying
Distribute every term of the first polynomial to every term of the second. Then combine like terms. Use FOIL for two binomials.
(x + 2)(x² − 3x + 1)
= x³ − 3x² + x + 2x² − 6x + 2
= x³ − x² − 5x + 2
Remainder Theorem
When polynomial p(x) is divided by (x − a), the remainder equals p(a). No long division needed — just evaluate the polynomial at x = a.
p(x) = x³ − 2x + 5, divided by (x − 2)
Remainder = p(2) = 8 − 4 + 5 = 9
Factor Theorem
(x − a) is a factor of p(x) if and only if p(a) = 0. To check if something is a factor, evaluate — don't divide.
Is (x − 3) a factor of x² − 5x + 6?
p(3) = 9 − 15 + 6 = 0 ✓
Yes — (x − 3) is a factor.
Worked example — Remainder Theorem
If p(x) = 2x³ − x² + 3x − 7, what is the remainder when p(x) is divided by (x − 2)?

By the Remainder Theorem: remainder = p(2)
p(2) = 2(8) − (4) + 3(2) − 7
= 16 − 4 + 6 − 7
= 11

The remainder is 11. No polynomial long division needed.
SAT strategy tips
Remainder Theorem saves 2 minutes
When the SAT asks for a remainder when dividing by (x − a), never do long division. Just evaluate p(a). If the SAT asks what value of a makes the remainder zero — that's asking for a root, so set p(a) = 0 and solve.
Factor Theorem — test by substitution
To check if (x − a) is a factor, substitute x = a into the polynomial. If the result is 0, it's a factor. If not, it's not. This is faster than any algebraic manipulation.
Subtract polynomials — distribute the negative
The most common error in polynomial subtraction: forgetting to distribute the minus sign. (3x² + 2) − (x² − 4) = 3x² + 2 − x² + 4 = 2x² + 6. Every term in the second polynomial changes sign.
Degree of product = sum of degrees
When multiplying two polynomials, the degree of the result equals the sum of the degrees. A degree-2 times a degree-3 gives a degree-5 polynomial. Use this to quickly check if your answer has the right leading term.
Practice questions
Problem
Simplify:
(2x³ − 4x + 3) − (x³ + 2x² − 5x + 1)
Distribute the negative sign to every term in the second polynomial: −(x³ + 2x² − 5x + 1) = −x³ − 2x² + 5x − 1. Then combine like terms by degree.
Question 1 · Polynomial Subtraction
Which expression is equivalent to the given expression?
Ax³ − 2x² + x + 2
Bx³ + 2x² − 9x + 2
Cx³ − 2x² − 9x + 4
Dx³ + 2x² + x + 4
Correct! x³ − 2x² + x + 2
(2x³ − 4x + 3) − (x³ + 2x² − 5x + 1)
= 2x³ − 4x + 3 − x³ − 2x² + 5x − 1
Group by degree:
x³: 2x³ − x³ = x³
x²: 0 − 2x² = −2x²
x: −4x + 5x = x
const: 3 − 1 = 2
= x³ − 2x² + x + 2 ✓
Not quite. Distribute the negative to ALL terms in the second polynomial: −x³ − 2x² + 5x − 1. Then combine: x³ terms, x² terms, x terms, and constants separately.
= x³ − 2x² + x + 2
Problem
The polynomial p(x) = x³ − 7x + 6.
Use the Remainder Theorem and Factor Theorem to answer the question.
To find the remainder when dividing by (x − a), compute p(a). To check if (x − a) is a factor, check if p(a) = 0.
Question 2 · Factor Theorem
Which of the following is a factor of p(x) = x³ − 7x + 6?
A(x − 3)
B(x + 3)
C(x − 4)
D(x + 4)
Correct! (x − 3) is a factor.
Test each option using Factor Theorem p(a) = 0:
p(3) = 27 − 21 + 6 = 12 ≠ 0...

Wait — let me recalculate:
p(3) = 27 − 21 + 6 = 12 ✗
p(−3) = −27 + 21 + 6 = 0 ✓ → (x+3) is a factor!
p(4) = 64 − 28 + 6 = 42 ✗
p(−4) = −64 + 28 + 6 = −30 ✗

So (x + 3) is the correct factor. Answer is B.
Not quite. Use the Factor Theorem: test each value by substituting into p(x). If p(a) = 0, then (x − a) is a factor. Try p(−3): (−3)³ − 7(−3) + 6 = −27 + 21 + 6 = 0 ✓
p(−3) = 0 → (x − (−3)) = (x + 3) is a factor
Problem
When the polynomial p(x) = 2x³ + kx² − 5x + 3 is divided by (x − 1), the remainder is 4.
By the Remainder Theorem, p(1) = remainder = 4. Substitute x = 1 into p(x), set equal to 4, and solve for k.
