Rational Expressions
Learn to simplify, multiply, divide, and add rational expressions — algebraic fractions — and solve rational equations by clearing denominators.
13 min read3 practice questions+20 pts on completion
What is a rational expression?
A rational expression is a fraction where numerator and denominator are polynomials. Rules mirror regular fractions: factor first, then simplify. The key rule: never cancel terms — only factors.
Simplifying
Factor fully. Cancel common factors (not terms).
(x²−4)/(x+2) = (x+2)(x−2)/(x+2) = x−2
Multiplying
Multiply numerators, multiply denominators. Factor and cancel before multiplying.
(x+1)/(x−3) · (x−3)/(x+2) = (x+1)/(x+2)
Dividing
Multiply by the reciprocal. Flip the second fraction, then multiply.
(x²−1)/x ÷ (x+1)/3 = (x−1)·3/x = 3(x−1)/x
Adding & Subtracting
Find LCD, rewrite each fraction with LCD, combine numerators, simplify.
1/x + 2/(x+1) = (x+1+2x)/[x(x+1)] = (3x+1)/[x(x+1)]
Solving a rational equation
3/(x−2) = 5/x
Multiply both sides by x(x−2):
3x = 5(x−2) → 3x = 5x−10 → x = 5 ✓
SAT strategy tips
Factor before anything else
Factor every numerator and denominator before multiplying, dividing, or simplifying. This reveals what cancels and keeps arithmetic manageable.
Never cancel terms — only factors
(x+3)/(x+5) cannot simplify by cancelling x. Only cancel when the same expression is a factor in both numerator and denominator, separated by multiplication — not addition.
Clear denominators to solve equations
Multiply both sides by the LCD to eliminate all fractions. This turns a rational equation into a simple linear or quadratic equation you already know how to solve.
Check for extraneous solutions
After solving, verify no denominator equals zero at your solution. If x = 2 makes a denominator zero, discard it — it's extraneous even if it solved the algebra correctly.
Practice questions
Problem
Simplify:
(x² + 5x + 6) / (x² − x − 6)
Factor both: numerator = (x+2)(x+3), denominator = (x+2)(x−3). Cancel the common factor.
Question 1 · Simplifying
Which expression is equivalent (for valid x)?
A(x+2)/(x−2)
B(x+3)/(x−3)
C(x+2)/(x−3)
D(x+3)/(x+2)
Correct!
x²+5x+6 = (x+2)(x+3)
x²−x−6 = (x+2)(x−3)
Cancel (x+2): → (x+3)/(x−3) ✓
Not quite. Factor both polynomials, then cancel the common factor (x+2).
(x+2)(x+3)/[(x+2)(x−3)] = (x+3)/(x−3)
Problem
Solve:
4/(x − 1) + 1 = 6/(x − 1)
Multiply every term by (x−1) to clear denominators, including the middle term 1·(x−1).
Question 2 · Rational Equation
What is the value of x?
Ax = 3
Bx = −1
Cx = 1
DNo solution
Correct! x = 3
Multiply by (x−1): 4 + (x−1) = 6
x + 3 = 6 → x = 3
Check: 3−1=2≠0 ✓ · 4/2+1=3=6/2 ✓
Not quite. Multiply every term by (x−1): the 1 becomes 1·(x−1) = x−1.
4 + x − 1 = 6 → x = 3
Problem
Add and simplify:
2/x + 3/(x + 2)
LCD = x(x+2). Convert: 2/x → 2(x+2)/[x(x+2)] and 3/(x+2) → 3x/[x(x+2)]. Add numerators.
Question 3 · Adding Rational Expressions
Which expression is equivalent?
A5 / (x² + 2x)
B(5x + 4) / (x² + 2x)
C(5x + 4) / (2x + 2)
D5 / (2x + 2)
Correct! (5x+4)/(x²+2x)
LCD = x(x+2)
2(x+2)/[x(x+2)] + 3x/[x(x+2)]
= (2x+4+3x)/(x²+2x) = (5x+4)/(x²+2x) ✓
Not quite. LCD = x(x+2). Rewrite both fractions with this denominator, then add numerators.
(2x+4+3x)/(x²+2x) = (5x+4)/(x²+2x)
