Radicals & Rational Exponents
Master operations with square roots, cube roots, and rational exponents — and learn the conversion that connects them.
13 min read3 practice questions+20 pts on completion
Radical ↔ Rational exponent conversion
Every radical can be rewritten as a rational (fractional) exponent. This is one of the most tested conversions on the SAT.
ⁿ√(aᵐ) = a^(m/n)    a^(1/n) = ⁿ√a    a^(m/n) = (ⁿ√a)ᵐ
The denominator of the exponent = the index of the radical · The numerator = the power
Key examples
√x = x^(1/2)
∛x = x^(1/3)
x^(2/3) = (∛x)² = ∛(x²)
x^(3/2) = (√x)³ = √(x³)
Exponent rules still apply
x^(1/2) · x^(1/2) = x¹ = x
x^(2/3) · x^(1/3) = x¹ = x
(x^(1/2))⁴ = x²
x^(−1/2) = 1/√x
Worked example
Simplify: (8x⁶)^(2/3)
= 8^(2/3) · (x⁶)^(2/3)
= (∛8)² · x⁴
= 4x⁴ ✓
SAT strategy tips
Convert radicals to exponents first
When an expression mixes radicals and exponents, convert everything to rational exponent form. Then apply the standard exponent rules you already know.
Denominator = root, numerator = power
In a^(m/n): n is the root (denominator) and m is the power (numerator). For a^(2/3): take the cube root first, then square — or vice versa (same result).
Simplify the radicand first
Before taking a root, factor out perfect squares (or cubes). √(72) = √(36·2) = 6√2. The SAT always has a "clean" simplification path.
Negative exponents = reciprocals
a^(−m/n) = 1/a^(m/n). Never leave a negative exponent in a final answer unless the question asks for it. Rewrite as a fraction.
Practice questions
Problem
Simplify:
(27x³)^(2/3)
Apply to each factor: 27^(2/3) = (∛27)² and (x³)^(2/3) = x². Cube root of 27 = 3.
Question 1 · Rational Exponents
Which expression is equivalent to (27x³)^(2/3)?
A9x²
B3x²
C9x
D3x³
Correct! 9x²
27^(2/3) = (∛27)² = 3² = 9
(x³)^(2/3) = x^(3·2/3) = x²
Result: 9x² ✓
Not quite. Apply the exponent to each factor separately. 27^(2/3) = (∛27)² = 9. (x³)^(2/3) = x².
9 · x² = 9x²
Problem
Which is equivalent to x^(3/2)?
x^(3/2)
The exponent 3/2 means: denominator 2 is the root (square root), numerator 3 is the power. So x^(3/2) = (√x)³ = √(x³).
Question 2 · Radical Conversion
Which expression equals x^(3/2)?
A∛(x²)
B√(x³)
Cx·√x · this is same as √(x³)
D(∛x)²
Correct! √(x³)
x^(3/2) = x^(3·(1/2)) = (x^(1/2))³ = (√x)³ = √(x³) ✓
Also equals x·√x since √(x³)=√(x²·x)=x√x.
Not quite. In x^(m/n): denominator n = root, numerator m = power. x^(3/2) → square root (denominator 2), cubed (numerator 3) → (√x)³ = √(x³).
x^(3/2) = √(x³)
Problem
Simplify completely:
√(50x⁴y²)
Factor the radicand: 50 = 25·2, x⁴ = (x²)², y² = y². Pull out perfect squares: √25 = 5, √(x⁴) = x², √(y²) = |y|. Assume y > 0.
Question 3 · Simplifying Radicals
Which is the simplified form?
A5x²y√2
B5x²√(2y²)
C25x²y√2
D5xy√2
Correct! 5x²y√2
√(50x⁴y²)
= √(25·2·x⁴·y²)
= √25 · √2 · √(x⁴) · √(y²)
= 5 · √2 · x² · y
= 5x²y√2 ✓
Not quite. Factor out all perfect squares: 50 = 25·2, x⁴ = (x²)², y² = y². Take √ of each perfect square separately.
√25·√2·x²·y = 5x²y√2
