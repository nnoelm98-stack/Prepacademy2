Exponential Functions
Learn to identify, evaluate, and interpret exponential growth and decay functions — and connect the equation to real-world models like population and compound interest.
13 min read3 practice questions+20 pts on completion
The exponential function
An exponential function has the form f(x) = a·bˣ, where b is the base (b > 0, b ≠ 1). The variable is in the exponent — this makes growth or decay far faster than any linear or polynomial function.
f(x) = a · bˣ
a = initial value (when x = 0) · b > 1: growth · 0 < b < 1: decay
Growth: b > 1
Each unit increase in x multiplies output by b. The function increases without bound.
f(x) = 500·(1.06)ˣ
6% growth per period.
f(0)=500, f(1)=530, f(2)=561.8
Decay: 0 < b < 1
Each unit increase in x multiplies output by b (a fraction). The function decreases toward zero.
f(x) = 1000·(0.8)ˣ
20% decrease per period.
f(0)=1000, f(1)=800, f(2)=640
SAT model types
Growth: f(t) = a(1 + r)ᵗ where r = growth rate
Decay: f(t) = a(1 − r)ᵗ where r = decay rate
Compound interest: A = P(1 + r/n)^(nt)
Half-life: A = A₀·(1/2)^(t/h) where h = half-life period
SAT strategy tips
Initial value = f(0) = a
In f(x) = a·bˣ, the initial value is a because b⁰ = 1. The SAT asks "what is the initial value?" — it's always the coefficient a, not the base b.
Identify growth vs. decay from b
b > 1 → growth. b between 0 and 1 → decay. For f(x) = 200·(0.75)ˣ: b = 0.75 < 1 → decay. The function loses 25% of its value per period.
Percent change from base b
If b = 1.08, the quantity grows 8% per period. If b = 0.92, it decreases 8% per period. The percent change = |b − 1| × 100%. This interpretation appears constantly on the SAT.
Compare exponential to linear
The SAT may give a table and ask whether the relationship is linear or exponential. Linear: constant differences. Exponential: constant ratios. Divide consecutive y-values — if the ratio is constant, it's exponential.
Practice questions
Problem
A population of bacteria starts at 400 and doubles every hour.
P(t) = 400 · 2ᵗ
After t hours, the population has doubled t times. Substitute t = 3 directly into the formula.
Question 1 · Exponential Growth
What is the population after 3 hours?
A2400
B3200
C1600
D6400
Correct! 3200
P(3) = 400 · 2³ = 400 · 8 = 3200 ✓
Not quite. Substitute t = 3: P(3) = 400 · 2³. Calculate 2³ first, then multiply by 400.
400 · 8 = 3200
Problem
A car's value depreciates. Its value after t years is:
V(t) = 24000 · (0.85)ᵗ
The base 0.85 = 1 − 0.15, meaning 15% depreciation per year. The initial value is 24000 (when t = 0).
Question 2 · Interpreting Decay
What does the value 0.85 represent in this model?
AThe car loses $0.85 in value each year
BThe car retains 85% of its value each year
CThe car's value after 85 years
DThe car gains 85% in value each year
Correct! In V(t) = 24000·(0.85)ᵗ, the base 0.85 means each year the car retains 85% of its previous value — equivalently, it loses 15% per year. This is exponential decay with a decay rate of 15%.
Not quite. In f(x) = a·bˣ, the base b is the multiplier applied each period. b = 0.85 means each year the output is multiplied by 0.85 — the car keeps 85% of its value (losing 15%).
b = 0.85 → retains 85% per year
Problem
Which table represents an exponential function?
Choose the table where consecutive y-values have a constant ratio.
For each table, divide each y-value by the previous one. If the ratio is constant, it's exponential. If the differences are constant, it's linear.
Question 3 · Identifying Exponential
Which (x, y) table shows exponential behavior?
Ax: 0,1,2,3 · y: 2,4,6,8 (differences = 2)
Bx: 0,1,2,3 · y: 3,9,27,81 (ratios = 3)
Cx: 0,1,2,3 · y: 1,4,9,16 (differences vary)
Dx: 0,1,2,3 · y: 5,10,15,20 (differences = 5)
Correct! Table B has y-values 3, 9, 27, 81. Each is 3 times the previous: 9/3=3, 27/9=3, 81/27=3. Constant ratio = 3 → exponential function f(x) = 3·3ˣ = 3^(x+1). Tables A and D are linear (constant differences). Table C is quadratic.
Not quite. For each option, compute the ratio of consecutive y-values (divide each by the previous). Exponential: constant ratio. Linear: constant difference.
Table B: 9/3=3, 27/9=3, 81/27=3 → constant ratio ✓
