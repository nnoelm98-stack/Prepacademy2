Function Notation & Operations
Master function notation, domain and range, composite functions, and the transformations that shift and reflect graphs — all tested frequently on the SAT.
13 min read3 practice questions+20 pts on completion
Function notation essentials
Functions map each input to exactly one output. The notation f(x) means "the output of function f when input is x." The SAT tests several key operations on functions.
Evaluating: f(a)
Substitute x = a into the function formula.
f(x) = 3x − 1
f(4) = 3(4)−1 = 11
f(−2) = 3(−2)−1 = −7
Composite: f(g(x))
Apply g first, then apply f to the result. Work from the inside out.
f(x)=2x+1, g(x)=x²
f(g(3))=f(9)=2(9)+1=19
g(f(3))=g(7)=49
Domain
All valid inputs (x-values). Exclude: values making denominators zero, or square roots of negatives.
f(x)=1/(x−3): domain all x≠3
g(x)=√(x−2): domain x≥2
Range
All possible outputs (y-values). For f(x)=x²: range is y≥0. For f(x)=|x|+1: range is y≥1.
f(x)=2x+3: range all reals
f(x)=x²+1: range y≥1
Graph transformations
f(x) + k → shift UP k units
f(x) − k → shift DOWN k units
f(x + h) → shift LEFT h units
f(x − h) → shift RIGHT h units
−f(x) → reflect over x-axis
f(−x) → reflect over y-axis
a·f(x), a>1 → vertical stretch
SAT strategy tips
Composite: always work inside-out
For f(g(x)), evaluate g(x) first, then plug that result into f. Don't try to substitute x into f directly — always resolve the inner function first.
f(x+2) shifts LEFT, not right
This is counterintuitive. f(x+2) shifts the graph LEFT by 2. f(x−2) shifts RIGHT by 2. The sign inside the parentheses is opposite to the direction of horizontal shift.
Domain restrictions: set denominator ≠ 0
To find domain restrictions, set each denominator equal to zero and solve. Those x-values are excluded. For square roots, set the radicand ≥ 0 and solve.
−f(x) flips vertically; f(−x) flips horizontally
The negative outside: −f(x) reflects over the x-axis (y-values flip sign). The negative inside: f(−x) reflects over the y-axis (x-values flip sign). Location of the negative determines the axis.
Practice questions
Problem
Given f(x) = x² − 3 and g(x) = 2x + 1
Find f(g(2))
Work inside-out. First find g(2), then plug that result into f. g(2) = 2(2)+1 = 5. Then f(5) = 5² − 3.
Question 1 · Composite Functions
What is f(g(2))?
A22
B5
C1
D25
Correct! f(g(2)) = 22
g(2) = 2(2)+1 = 5
f(g(2)) = f(5) = 5²−3 = 25−3 = 22 ✓
Not quite. Work inside-out: first compute g(2) = 2(2)+1. Then substitute that answer into f.
g(2)=5 → f(5)=25−3=22
Problem
The graph of f(x) is shifted 3 units right and 2 units down.
New function: f(x − 3) − 2
Right shift h units → replace x with (x−h). Down k units → subtract k from the whole function. Right 3 → (x−3). Down 2 → −2.
Question 2 · Transformations
If f(x) = x², what is the equation of the transformed graph?
A(x+3)² + 2
B(x−3)² + 2
C(x−3)² − 2
D(x+3)² − 2
Correct! (x−3)² − 2
Right 3 → replace x with (x−3): (x−3)²
Down 2 → subtract 2: (x−3)² − 2
Vertex moves from (0,0) to (3,−2) ✓
Not quite. Right shift by h: use (x−h) inside. Down by k: subtract k outside. Right 3 → (x−3). Down 2 → −2.
(x−3)² − 2
Problem
A function f has domain all real x where:
f(x) = √(2x − 6) / (x − 5)
Two restrictions: (1) the radicand must be ≥ 0: 2x−6 ≥ 0 → x ≥ 3. (2) denominator ≠ 0: x ≠ 5. Combine both conditions.
Question 3 · Domain
What is the domain of f(x)?
Ax ≥ 3
Bx > 3, x ≠ 5
Cx ≥ 3, x ≠ 5
DAll real numbers except x = 5
Correct! x ≥ 3, x ≠ 5
Radical: 2x−6 ≥ 0 → x ≥ 3
Denominator: x−5 ≠ 0 → x ≠ 5
Combined: x ≥ 3 AND x ≠ 5 ✓
So domain is [3,∞) excluding {5}
Not quite. Check two conditions: radicand ≥ 0 (gives x ≥ 3) AND denominator ≠ 0 (gives x ≠ 5). Both must hold simultaneously.
