Inequalities — Advanced
Master absolute value equations and inequalities — one of the most frequently tested advanced algebra topics on the SAT — and learn the two-case method that solves every problem of this type.
13 min read3 practice questions+20 pts on completion
What absolute value means
The absolute value of a number is its distance from zero on the number line — always non-negative. |5| = 5 and |−5| = 5 because both are 5 units from zero.

This distance interpretation is the key to solving absolute value equations and inequalities: you must consider two cases — one where the expression inside is positive, and one where it is negative.
|x| = a  →  x = a  OR  x = −a
Always two cases. Always consider both.
Equations vs. inequalities — different rules
Absolute value equation: |A| = b
Split into two equations. Solve each separately. Check both answers in the original.
|2x − 3| = 7
Case 1: 2x − 3 = 7 → x = 5
Case 2: 2x − 3 = −7 → x = −2
Solutions: x = 5 or x = −2
|A| < b → "AND" (between)
Less than → bounded solution. The expression is between −b and b simultaneously.
|2x − 3| < 7
−7 < 2x − 3 < 7
−4 < 2x < 10
−2 < x < 5
|A| > b → "OR" (outside)
Greater than → two separate solution regions. The expression is either very positive or very negative.
|2x − 3| > 7
Case 1: 2x − 3 > 7 → x > 5
Case 2: 2x − 3 < −7 → x < −2
Solution: x < −2 or x > 5
Quick memory trick
Less than → AND → one connected interval (between two values)

Greater than → OR → two separate rays (outside two values)
"Less-and, great-or"
Full worked example
Solve: |3x + 6| ≥ 12

This is |A| ≥ b → "OR" case (greater than or equal)
Case 1: 3x + 6 ≥ 12 → 3x ≥ 6 → x ≥ 2
Case 2: 3x + 6 ≤ −12 → 3x ≤ −18 → x ≤ −6
Solution: x ≤ −6 or x ≥ 2

Check x = 3: |3(3)+6| = |15| = 15 ≥ 12 ✓
Check x = −7: |3(−7)+6| = |−15| = 15 ≥ 12 ✓
Check x = 0: |0+6| = 6 ≥ 12? ✗ (correctly excluded)
Critical rule — no solution case
If b is negative, the equation |A| = b has no solution — absolute value is always ≥ 0, so it can never equal a negative number. Similarly, |A| < −3 has no solution. The SAT tests this. Always check if b < 0 before solving.
SAT strategy tips
Isolate the absolute value first
Before splitting into cases, get the absolute value expression alone on one side. Don't split until |expression| = number is fully set up.
Check both solutions
After solving both cases of an equation, substitute each answer back into the original. Occasionally one solution is extraneous (doesn't actually satisfy the original).
Less-than → compact interval
|x − a| < d means x is within distance d of a: the solution is a − d < x < a + d. This interpretation is faster than algebraic splitting for simple problems.
Greater-than → two rays
|x − a| > d means x is more than distance d away from a: x < a − d or x > a + d. Picture the number line — two arrows pointing outward.
Practice questions
Problem
Solve the absolute value equation:
|2x − 5| = 11
Split into two cases: 2x − 5 = 11 and 2x − 5 = −11. Solve each. Both solutions are valid — check them in the original equation.
Question 1 · Absolute Value Equation
What are all values of x that satisfy the equation?
Ax = 8 only
Bx = 8 or x = −3
Cx = 3 or x = −8
DNo solution
Correct! x = 8 or x = −3
Case 1: 2x − 5 = 11 → 2x = 16 → x = 8
Case 2: 2x − 5 = −11 → 2x = −6 → x = −3
Check x=8: |16−5| = |11| = 11 ✓
Check x=−3: |−6−5| = |−11| = 11 ✓
Not quite. Remember absolute value equations always have two cases. Set the inside equal to +11 AND equal to −11. Solve both equations separately.
2x − 5 = 11 → x = 8
2x − 5 = −11 → x = −3
Problem
Solve the absolute value inequality:
|x + 4| ≤ 7
Less than (or equal) → "AND" case → write as a compound inequality: −7 ≤ x + 4 ≤ 7, then subtract 4 from all three parts.
Question 2 · Absolute Value Inequality (<)
Which describes all values of x that satisfy the inequality?
Ax ≤ 3 or x ≥ −11
B−3 ≤ x ≤ 11
C−11 ≤ x ≤ 3
Dx ≤ −11 or x ≥ 3
Correct! −11 ≤ x ≤ 3
|x + 4| ≤ 7 → −7 ≤ x + 4 ≤ 7
Subtract 4: −11 ≤ x ≤ 3
Check x=0: |0+4|=4 ≤ 7 ✓ (inside)
Check x=−11: |−11+4|=7 ≤ 7 ✓ (boundary)
Check x=5: |5+4|=9 ≤ 7 ✗ (correctly excluded)
Not quite. "Less than or equal" → AND → compact interval. Write −7 ≤ x + 4 ≤ 7 and subtract 4 from all three parts.
−7 − 4 ≤ x ≤ 7 − 4
−11 ≤ x ≤ 3
Problem
A machine is calibrated to fill bottles with exactly 500 ml. Due to mechanical variation, the actual fill amount f can differ from 500 ml by at most 8 ml.
|f − 500| ≤ 8
This models the acceptable range. Solve the inequality to find the minimum and maximum acceptable fill amounts.
Question 3 · Real-World Absolute Value
Which describes the acceptable range of fill amounts f?
Af ≤ 492 or f ≥ 508
B492 < f < 508
C492 ≤ f ≤ 508
Df = 492 or f = 508
Correct! 492 ≤ f ≤ 508
|f − 500| ≤ 8
−8 ≤ f − 500 ≤ 8
Add 500: 492 ≤ f ≤ 508
The boundary values (492 and 508) are included because the inequality is ≤ not <. A fill of exactly 492 or exactly 508 is still acceptable.
Not quite. Solve |f − 500| ≤ 8 as a compound inequality. The ≤ sign means the boundaries are included — a fill of exactly 492 or 508 is still within tolerance.
−8 ≤ f − 500 ≤ 8 → 492 ≤ f ≤ 508
