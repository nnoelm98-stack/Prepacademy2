Absolute Value
Go deeper on absolute value — learn its key algebraic properties, how to evaluate and simplify expressions involving absolute value, and how the SAT uses it in multi-step problems.
12 min read3 practice questions+20 pts on completion
Key properties of absolute value
Absolute value measures distance from zero — it is always non-negative. Beyond the basic definition, knowing these algebraic properties lets you simplify and evaluate expressions quickly.
|a| ≥ 0    for all real a
|a| = |−a|    (symmetric)
|ab| = |a| · |b|    (multiplicative)
|a + b| ≤ |a| + |b|    (triangle inequality)
These hold for all real numbers a and b.
|a²| = a² always
Since a² is always non-negative, the absolute value has no effect. This simplifies many expressions.
|x²| = x²   (for any real x)
|x² − 4| ≠ x² − 4   (could be negative)
√(x²) = |x|
The square root of x² is the absolute value of x — not x itself. This matters when x could be negative.
√(9) = 3 ✓
√(x²) = |x| ← not just x
If x = −4: √(16) = 4 = |−4| ✓
|a/b| = |a|/|b| (b ≠ 0)
Absolute value distributes over multiplication and division — but NOT over addition or subtraction.
|−6/2| = |−3| = 3 ✓
|6|/|2| = 3 ✓ (same result)
|3 − 7| ≠ |3| − |7| ✗
|a − b| = distance between a and b
The absolute value of a difference gives the distance between two points on a number line — regardless of order.
|3 − 8| = 5 (distance from 3 to 8)
|8 − 3| = 5 (same distance)
|x − 5| = 3 means x is 3 away from 5
Worked example — multi-step absolute value
If |x − 3| = 5, what are the possible values of |x|?

Step 1 — solve for x:
x − 3 = 5 → x = 8  OR  x − 3 = −5 → x = −2
Step 2 — evaluate |x| for each:
|8| = 8  OR  |−2| = 2
So |x| = 8 or |x| = 2

Note: The SAT might ask for the sum or product of these values: 8 + 2 = 10, or 8 × 2 = 16.
Most common absolute value mistake
Removing absolute value bars incorrectly: Students often write |x + 3| = x + 3, forgetting that if x + 3 is negative, this is wrong. Never remove absolute value bars unless you know the sign of the expression inside. Always consider both cases.
SAT strategy tips
Evaluate before simplifying
When given a specific value of x, substitute first, then apply the absolute value. Don't try to simplify the general expression — plug in numbers and evaluate.
√(x²) = |x| — always
If the SAT asks to simplify √(x²) or √((x−3)²), the answer is |x| or |x−3|, not x or x−3. The square root is always non-negative.
Distance interpretation saves time
|x − a| = b means x is exactly b units from a. Instead of algebra, just add and subtract: x = a + b or x = a − b. Faster on simple problems.
Check if the expression inside can be negative
Before removing |bars|, ask: can the expression inside be negative for any valid x? If yes, keep the absolute value. If the expression is always non-negative (like x²), you can simplify.
Practice questions
Problem
If x = −4, evaluate the expression:
|3x + 2| − |x − 1|
Substitute x = −4 into each absolute value separately. Calculate what's inside each |bar|, then take the absolute value, then subtract.
Question 1 · Evaluating Expressions
What is the value of the expression when x = −4?
A−15
B5
C15
D−5
Correct! 5
|3(−4) + 2| − |(−4) − 1|
= |−12 + 2| − |−5|
= |−10| − |−5|
= 10 − 5
= 5 ✓
Not quite. Substitute x = −4 carefully into each part. Calculate inside the bars first: 3(−4)+2 = −10, and (−4)−1 = −5. Then take absolute values of each: |−10| = 10, |−5| = 5. Finally subtract.
10 − 5 = 5
Problem
Given that |2x − 6| = 10, find all possible values of x², then determine which value of x² is larger.
|2x − 6| = 10
First solve for x (two cases). Then square each solution. The SAT often asks for x² or |x| after solving an absolute value equation — don't stop at x.
Question 2 · Multi-Step Absolute Value
What is the sum of all possible values of x?
A6
B8
C−2
D4
Correct! Sum = 6
|2x − 6| = 10
Case 1: 2x − 6 = 10 → 2x = 16 → x = 8
Case 2: 2x − 6 = −10 → 2x = −4 → x = −2
Sum of solutions: 8 + (−2) = 6 ✓

Note: For any |ax + b| = c, the sum of solutions always equals −b/a. Here: −(−6)/2 = 3... wait, the midpoint is 3 and solutions are 3±5, so 8 and −2, sum = 6 ✓
Not quite. Solve both cases: 2x − 6 = 10 gives one solution, and 2x − 6 = −10 gives the other. Add the two solutions together.
x = 8 and x = −2
Sum: 8 + (−2) = 6
Problem
On a number line, point A is at position −3 and point B is at position 7. Point P is at position x.
The condition that P is closer to A than to B can be written as:
|x − (−3)| < |x − 7|
Use the distance interpretation: |x + 3| is P's distance from A, and |x − 7| is P's distance from B. Square both sides to remove the absolute values, then solve the resulting inequality.
Question 3 · Distance & Absolute Value
For which values of x is point P closer to A than to B?
Ax < 2
Bx > 2
Cx < 5
D−3 < x < 7
Correct! x < 2
The midpoint between −3 and 7 is (−3+7)/2 = 2.
P is closer to A when x is to the left of the midpoint: x < 2.

Algebraically: |x+3| < |x−7|
Square both sides: (x+3)² < (x−7)²
x²+6x+9 < x²−14x+49
20x < 40 → x < 2 ✓
Not quite. The midpoint between −3 and 7 is 2. Points to the left of 2 are closer to A (at −3), and points to the right are closer to B (at 7). Which inequality captures "to the left of the midpoint"?
Midpoint = (−3+7)/2 = 2
Closer to A: x < 2
