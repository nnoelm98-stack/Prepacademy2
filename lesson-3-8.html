Linear Functions & Slope
Connect linear equations to function notation, master average rate of change from tables and graphs, and learn to recognize when the SAT is really asking about slope in disguise.
13 min read3 practice questions+20 pts on completion
Functions vs. equations — what changes
A linear function is a linear equation written using function notation: f(x) instead of y. The notation f(x) emphasizes that the output depends on the input x — and allows the SAT to ask questions like "find f(3)" or "for what value of x does f(x) = 7?"
f(x) = mx + b
f(x) is read "f of x" — the output when input is x
m = slope (rate of change) · b = f(0) = y-intercept (initial value)
ConceptWhat it meansHow to calculate
f(a)The output of the function when x = aSubstitute x = a into the equation and simplify
f(a) = bFind the input x that gives output bSet mx + c = b and solve for x
Slope mChange in output per unit change in inputm = (f(x₂) − f(x₁)) / (x₂ − x₁)
Average rate of changeThe slope between two specific pointsSame formula as slope — applied to any two points
f(0)The y-intercept — value when x = 0Substitute x = 0, or read b directly from f(x) = mx + b
Rate of change from a table
The SAT frequently gives a table of (x, y) or (x, f(x)) values and asks for the rate of change (slope) or a missing value. For a linear function, the rate of change is constant — so any two rows give the same slope.
Check linearity first
For a table to represent a linear function, equal changes in x must produce equal changes in y. If Δx is constant and Δy is constant, the function is linear.
x: 0, 2, 4, 6
y: 3, 7, 11, 15
Δx = 2, Δy = 4 → slope = 4/2 = 2 ✓
Find a missing value
Once you have the slope, use point-slope or substitute into y = mx + b to find any missing value in the table.
slope = 2, passes through (0,3)
f(x) = 2x + 3
f(5) = 2(5) + 3 = 13
Worked example — average rate of change
f(x) = 3x² − 2x + 1. Find the average rate of change from x = 1 to x = 4.

f(1) = 3(1) − 2(1) + 1 = 2
f(4) = 3(16) − 2(4) + 1 = 48 − 8 + 1 = 41
Average rate of change = (41 − 2)/(4 − 1) = 39/3 = 13

Note: For a linear function, the average rate of change equals the slope everywhere. For non-linear functions, it varies by interval.
SAT strategy tips
f(x) = k means solve for x
When the SAT asks "for what value of x does f(x) = 7?", that's just asking you to solve an equation. Set the function equal to 7 and solve — it's not asking for a function value.
Average rate of change = slope formula
The phrase "average rate of change" always means (f(b)−f(a))/(b−a). For a linear function this equals the slope. For any function, it's the slope of the secant line between two points.
Slope from a table: pick any two rows
For linear functions, every pair of rows gives the same slope. Pick the two rows with the cleanest numbers to minimize arithmetic errors.
"Rate" in word problems = slope
Any word problem mentioning a constant rate — miles per hour, dollars per item, degrees per minute — is describing slope. Identify the unit rate and that's your m in f(x) = mx + b.

To find f(a), substitute a for x. To find where f(x) = k, set −3x + 11 = k and solve for x.

Problem
A car rental company charges a base fee of $25 plus $0.18 per mile driven. A competitor charges $40 flat with no mileage fee.
Let C₁(m) = cost at Company 1 and C₂(m) = cost at Company 2, where m = miles driven.
Write both as functions: C₁(m) = 25 + 0.18m and C₂(m) = 40. Find where the two functions are equal — that's the break-even mileage.
Question 3 · Linear Functions — Real World
At how many miles do both companies charge the same total cost?
Aapproximately 56 miles
Bapproximately 83 miles
Capproximately 138 miles
Dapproximately 222 miles
Correct! ≈ 83 miles
Set C₁(m) = C₂(m):
25 + 0.18m = 40
0.18m = 15
m = 15/0.18 = 83.3̄ miles

Below 83 miles → Company 2 is cheaper (flat fee)
Above 83 miles → Company 1 is cheaper (no flat fee)
At ≈ 83 miles → same cost ✓
Not quite. Set the two cost functions equal: 25 + 0.18m = 40. Solve for m by subtracting 25 from both sides, then dividing by 0.18.
0.18m = 15 → m = 15 ÷ 0.18 ≈ 83.3
