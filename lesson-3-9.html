Introduction to Quadratics
Learn the standard form of a quadratic expression, master FOIL and the three special product patterns, and practice expanding and identifying quadratic expressions — the foundation for all quadratic solving.
13 min read3 practice questions+20 pts on completion
What is a quadratic?
A quadratic expression contains a variable raised to the second power as its highest degree term, written in standard form. Its graph is always a parabola.
ax² + bx + c
a ≠ 0 · a = leading coefficient · b = linear coefficient · c = constant (y-intercept)
a — leading coefficient
Determines parabola direction and width. a > 0 opens up; a < 0 opens down.
2x² + 3x + 1 → a = 2
b — linear coefficient
Affects horizontal position of vertex. Axis of symmetry: x = −b/(2a).
2x² + 3x + 1 → b = 3
c — constant term
Equals the y-intercept — value when x = 0. Read directly from standard form.
2x² + 3x + 1 → c = 1
The three special products — memorize these
Perfect square — sum
(a + b)² = a² + 2ab + b²
Middle term is always 2ab — the most frequently missed pattern.
(x + 5)² = x² + 10x + 25
(2x + 3)² = 4x² + 12x + 9
Perfect square — difference
(a − b)² = a² − 2ab + b²
Last term always positive. Middle term negative.
(x − 4)² = x² − 8x + 16
(3x − 1)² = 9x² − 6x + 1
Difference of squares
(a + b)(a − b) = a² − b²
Middle terms cancel. No linear term in the result.
(x + 7)(x − 7) = x² − 49
(2x + 3)(2x − 3) = 4x² − 9
General FOIL
(x + p)(x + q) = x² + (p+q)x + pq
Linear coefficient = sum of p, q. Constant = product of p, q.
(x + 3)(x + 5) = x² + 8x + 15
(x − 2)(x + 6) = x² + 4x − 12
Worked example
Expand: (3x − 2)² − (x + 4)(x − 4)

Part 1: (3x − 2)² = 9x² − 12x + 4
Part 2: (x + 4)(x − 4) = x² − 16
Result: (9x² − 12x + 4) − (x² − 16) = 8x² − 12x + 20
SAT strategy tips
Memorize the three special products
The SAT uses these constantly. Expanding (a+b)², (a−b)², and (a+b)(a−b) in 3 seconds without FOIL is a major time advantage on the no-calculator section.
(a+b)² ≠ a² + b²
The most common quadratic mistake: forgetting the middle term. (x+3)² = x² + 6x + 9, NOT x² + 9. The middle term 2ab is always there in a perfect square.
c is the y-intercept always
In ax² + bx + c, the constant c is the y-intercept. The SAT often asks for this — just read it directly without substituting x = 0.
Sum and product pattern for factoring
For x² + bx + c = (x+p)(x+q): p + q = b and p × q = c. Find two numbers that add to b and multiply to c — that's the foundation of factoring in Lesson 3.10.
Practice questions
Problem
Expand the expression:
(2x + 5)²
Use (a + b)² = a² + 2ab + b² with a = 2x, b = 5. Middle term = 2·(2x)·5 = 20x. Don't forget it!
Question 1 · Perfect Square
Which expression is equivalent to (2x + 5)²?
A4x² + 25
B4x² + 10x + 25
C4x² + 20x + 25
D2x² + 20x + 25
Correct! 4x² + 20x + 25
(2x)² + 2·(2x)·5 + 5² = 4x² + 20x + 25
A forgets the middle term. B uses 2·5=10 instead of 20x. D squares 2x incorrectly as 2x² instead of 4x².
Not quite. Apply (a+b)² = a² + 2ab + b² with a=2x, b=5. (2x)² = 4x². Middle term: 2×(2x)×5 = 20x.
4x² + 20x + 25
Problem
Simplify the expression:
(x + 6)(x − 6) − (x − 3)²
Use difference of squares for the first part: (x+6)(x−6) = x² − 36. Use perfect square for the second: (x−3)² = x² − 6x + 9. Then subtract carefully — watch the signs.
Question 2 · Special Products
Which expression is equivalent to (x + 6)(x − 6) − (x − 3)²?
A6x − 45
B−27
C6x − 27
D2x² − 6x − 45
Correct! 6x − 45
(x+6)(x−6) = x² − 36
(x−3)² = x² − 6x + 9
Result: (x² − 36) − (x² − 6x + 9)
= x² − 36 − x² + 6x − 9
= 6x − 45 ✓
Note: x² terms cancel!
Not quite. Expand each part first: (x+6)(x−6) = x²−36 and (x−3)² = x²−6x+9. Then subtract the entire second expression — distribute the negative sign to every term inside.
x²−36 − x²+6x−9 = 6x−45
Problem
The expression x² + kx + 36 is a perfect square trinomial — it equals (x + n)² for some integer n.
For a perfect square trinomial (x + n)² = x² + 2nx + n². The constant term is n², so n² = 36 → n = 6 or n = −6. The middle coefficient k = 2n.
Question 3 · Perfect Square Identification
What are the possible values of k?
Ak = 6 only
Bk = 12 only
Ck = 12 or k = −12
Dk = 6 or k = −6
Correct! k = 12 or k = −12
For x² + kx + 36 = (x + n)²:
n² = 36 → n = 6 or n = −6
k = 2n:
If n = 6: k = 12 → (x+6)² = x²+12x+36 ✓
If n = −6: k = −12 → (x−6)² = x²−12x+36 ✓
Not quite. In a perfect square (x+n)², the constant is n² and the middle coefficient is 2n. If n² = 36, what are the two possible values of n? Then for each n, what is k = 2n?
n = ±6 → k = 2(6)=12 or k = 2(−6)=−12
