Coordinate Geometry
Master distance, midpoint, and partition formulas — and apply coordinate geometry to find areas, perimeters, and properties of shapes plotted in the xy-plane.
12 min read3 practice questions+20 pts on completion
The core coordinate formulas
Distance: d = √[(x₂−x₁)² + (y₂−y₁)²]
Midpoint: M = ((x₁+x₂)/2, (y₁+y₂)/2)
Partition: P = (x₁ + m/(m+n)·(x₂−x₁), y₁ + m/(m+n)·(y₂−y₁))

Worked example — partition point
Point P divides segment AB in ratio 2:3, where A = (1, 2) and B = (6, 12).

P_x = 1 + 2/(2+3) × (6−1) = 1 + (2/5)(5) = 1 + 2 = 3
P_y = 2 + 2/(2+3) × (12−2) = 2 + (2/5)(10) = 2 + 4 = 6
P = (3, 6)
SAT strategy tips
Distance = Pythagorean theorem
The distance formula is just a² + b² = c² in disguise: Δx and Δy are the two legs, the distance is the hypotenuse. If the numbers are clean, check if they're a Pythagorean triple before computing the square root.
Midpoint: average both coordinates
Average the x-values and average the y-values separately. If you know the midpoint and one endpoint, set up equations: midpoint = (x₁+x₂)/2 and solve for the unknown endpoint.
Partition: identify which endpoint you start from
In ratio m:n, you move m/(m+n) of the way from the first point to the second. Always identify which point is "first" from the problem statement — getting this wrong flips the answer.
Check collinearity with slope
Three points are collinear if any two pairs give the same slope. If slopes AB and BC are equal, then A, B, C are on the same line. Use this to verify answers in coordinate geometry problems.

Points A = (2, −1) and B = (8, 7) are endpoints of a segment.
Distance: √[(8−2)² + (7−(−1))²] = √[36+64] = √100. Midpoint: ((2+8)/2, (−1+7)/2).

Problem
Point P divides segment from C = (0, 0) to D = (10, 15) in the ratio 2:3 (measured from C).
Use partition formula: P_x = 0 + 2/(2+3) × (10−0) = 2/5 × 10 = 4. P_y = 0 + 2/5 × 15 = 6.

Problem
Triangle ABC has vertices at A = (0, 0), B = (6, 0), and C = (4, 5).
Area of triangle with one side on x-axis: base AB = 6 (horizontal distance). Height = y-coordinate of C = 5. Area = ½ × base × height.
