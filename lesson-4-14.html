Polynomial & Rational Functions
Master end behavior, zeros, and graph features of polynomial functions — and vertical/horizontal asymptotes, holes, and domain restrictions of rational functions.

Polynomial function features
FeatureHow to find itExample
Zeros / x-interceptsSet f(x) = 0, solve. Each factor (x−r) gives a root at x = r.f(x)=(x−2)(x+3)(x−1) has zeros at x=2,−3,1
y-interceptSubstitute x = 0.f(0) = (0−2)(0+3)(0−1) = (−2)(3)(−1) = 6
End behavior (even degree)Both ends go same direction. a>0: both up. a<0: both down.f(x)=2x⁴−...: as x→±∞, f→+∞
End behavior (odd degree)Ends go opposite directions. a>0: left down, right up.f(x)=x³+...: left down, right up
Multiplicity of a rootIf (x−r)² appears → root touches axis but doesn't cross. (x−r)¹ → crosses axis.f(x)=(x−2)²(x+1): touches at x=2, crosses at x=−1
Rational function features
A rational function is a fraction of two polynomials: f(x) = p(x)/q(x). Its key features come from the numerator (zeros) and denominator (vertical asymptotes or holes).
FeatureHow to find it
Vertical asymptoteSet denominator = 0, check that the numerator is NOT also 0 at that x. If so, there's a vertical asymptote at x = that value.
Hole (removable discontinuity)If both numerator AND denominator = 0 at the same x, factor and cancel — that x is a hole, not an asymptote.
Horizontal asymptoteCompare degrees. If deg(num) < deg(den): y = 0. If equal: y = leading coeff ratio. If deg(num) > deg(den): no horizontal asymptote.
x-interceptsSet numerator = 0 (after cancelling holes). The remaining uncancelled zeros give x-intercepts.
Worked example
For f(x) = (x²−4) / (x²−x−6), find all features.

Factor: (x+2)(x−2) / (x−3)(x+2)
Cancel (x+2): = (x−2)/(x−3) with a hole at x = −2
Vertical asymptote: x = 3 (denominator = 0, not cancelled)
Horizontal asymptote: y = 1 (equal degree, ratio of leading coefficients)
x-intercept: x = 2 (numerator = 0 after cancellation)
SAT strategy tips
End behavior: focus on leading term only
For large |x|, only the leading term matters. f(x) = −3x⁵ + ... behaves like −3x⁵ as x→±∞. Negative odd degree → left up, right down.
Factor before identifying asymptotes
Always factor numerator and denominator completely before labeling asymptotes or holes. If the same factor cancels, it's a hole. If it stays in the denominator, it's a vertical asymptote.
Horizontal asymptote: compare degrees
deg(num) < deg(den) → y = 0. Same degree → y = ratio of leading coefficients. deg(num) > deg(den) → no horizontal asymptote (oblique or none). Memorize these three cases.
Multiplicity affects graph behavior at roots
Even multiplicity (power 2, 4, ...) → graph touches and bounces off the x-axis. Odd multiplicity (power 1, 3, ...) → graph crosses through the x-axis. The SAT uses this to test graph identification questions.

Problem
The rational function:
f(x) = (x² − 9) / (x² − x − 6)
Factor both: numerator = (x+3)(x−3). Denominator = (x−3)(x+2). Cancel the common factor (x−3) → hole at x=3. The remaining denominator factor (x+2) gives a vertical asymptote at x=−2.

Problem
A polynomial function f has roots at x = −1 (multiplicity 2) and x = 4 (multiplicity 1), and f(0) = −8.
Factored form: f(x) = a(x+1)²(x−4). Use f(0)=−8 to find a: −8 = a(1)²(−4) = −4a → a = 2. The even multiplicity at x=−1 means the graph touches but doesn't cross there.
