Linear & Exponential Models in Context
Master the art of choosing between linear and exponential models from data, graphs, and word descriptions — and practice writing, interpreting, and comparing models in complex real-world contexts.
13 min read3 practice questions+20 pts on completion
Choosing the right model
Linear model — constant difference
Use when equal changes in x produce equal changes in y. The rate of change is constant. Graph is a straight line.
Table test: Δy is constant for equal Δx
Words: "adds $50 per month," "increases by 200 per year"
f(x) = mx + b
Exponential model — constant ratio
Use when equal changes in x produce equal ratios of y. The percent change is constant. Graph curves.
Table test: y₂/y₁ is constant for equal Δx
Words: "grows by 8% annually," "doubles every 5 years"
f(x) = a·bˣ
From a table — check differences vs. ratios
If consecutive y-values have constant differences → linear. If they have constant ratios → exponential. Compute both and see which is consistent.
From a word problem — key phrases
"By X per period" → linear (constant amount). "By X% per period" → exponential (constant rate). "X times as large" → exponential.
When linear eventually overtakes exponential
For small values, a linear model can be larger. But exponential always wins for large enough x because it grows without bound faster than any linear function.
Fitting a model to two points
For linear: use slope formula + y-intercept. For exponential: set up f(x) = a·bˣ, use two points to create two equations, solve for a and b.
Worked example — fitting an exponential model
A population was 2,000 in year 0 and 2,500 in year 4. Assuming exponential growth, find the model.

f(x) = a·bˣ · f(0) = a = 2,000
f(4) = 2,000·b⁴ = 2,500
b⁴ = 1.25 → b = 1.25^(1/4) ≈ 1.0574
f(x) = 2,000 · (1.0574)ˣ → about 5.74% annual growth
SAT strategy tips
Table: check differences first, then ratios
For any table in the calculator section, compute consecutive differences (Δy). If constant → linear. If not constant, compute consecutive ratios (y₂/y₁). If constant → exponential. This two-step check handles every model identification question.
"Percent change" always signals exponential
Any phrase containing "percent," "rate," or "times as large" describes exponential behavior. A fixed dollar or unit amount signals linear. This vocabulary distinction appears in almost every "identify the model" question.
The y-intercept is always f(0) = a
In both linear (f(0) = b) and exponential (f(0) = a), the y-intercept is the value when x = 0. For exponential, this is the starting value a. For linear, it's the fixed offset b. The SAT always asks about f(0).
Which model fits better: compare residuals
If the SAT gives a scatterplot and asks which model fits better, check whether the residuals (vertical distances from points to curve) are smaller for the linear or exponential fit. The better model has smaller, more random residuals.

AAfter approximately 5 years
BAfter approximately 10 years
CAfter approximately 15 years

Correct! ≈ 15 years
A(t) = 500 + 40t · B(t) = 400·(1.08)ᵗ
t=10: A=900, B=400·2.159=864 → A still leads
t=15: A=1100, B=400·3.172=1269 → B now leads!
t=14: A=1060, B=400·2.937=1175 → B leads at t=14
So B first exceeds A around t=13-14. Closest answer: C (15 years)

Problem
The function P(t) = 1,200(0.88)ᵗ models the number of active subscribers to a streaming service t months after a price increase.
Identify a = 1,200 (initial subscribers) and b = 0.88 (monthly factor). Decay rate = 1 − 0.88 = 0.12 = 12%. The model predicts subscribers decrease by 12% each month.
Question 3 · Interpreting Exponential Models
Which statement best interprets this model?
AThe service started with 880 subscribers and loses 12% of them each month.
BThe service started with 1,200 subscribers and loses approximately 12% of subscribers each month.
CThe service started with 1,200 subscribers and gains 88 new subscribers each month.
DThe service loses 0.88 subscribers per month starting from 1,200.
Correct! P(0) = 1,200·(0.88)⁰ = 1,200 → started with 1,200 subscribers ✓. Base 0.88 = 1−0.12 → 12% monthly decay ✓. Option A misreads a as 880 (that's 0.88×1,000 — not from the formula). Option C confuses 0.88 with an additive rate. Option D treats the model as linear.
Not quite. In P(t) = a·bᵗ: a = P(0) = 1,200 (initial value). b = 0.88 = 1 − 0.12, meaning 12% decay per month. Which option correctly states both the starting value and the rate?
