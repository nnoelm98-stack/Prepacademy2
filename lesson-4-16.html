Two-Variable Data
Master scatterplots, lines and curves of best fit, residuals, and two-way frequency tables at a deeper level — the data reasoning the SAT tests in its most sophisticated questions.
13 min read3 practice questions+20 pts on completion
Scatterplot analysis — the full toolkit
Linear vs. nonlinear fit
If residuals form a curved pattern (all positive then all negative), a linear model is a poor fit — try a quadratic or exponential curve instead.
Random residuals around zero → good linear fit
U-shaped residuals → try quadratic fit
Residual plots
A residual plot shows (x, actual − predicted) for each point. A good model has residuals randomly scattered around y = 0 with no visible pattern.
Outliers and influential points
An outlier far from the trend can shift the line of best fit significantly. Always check whether removing an outlier changes the slope or intercept substantially.
Two-way tables — relative frequency
Relative frequency = cell count / total. Row relative frequency uses the row total as denominator. Column relative frequency uses the column total.
Cell count 40, row total 100 → row relative freq = 40%
Cell count 40, grand total 200 → overall freq = 20%
Correlation coefficient r
r ranges from −1 to +1. |r| close to 1 → strong association. |r| close to 0 → weak association. Sign indicates direction. r = 0 does NOT mean no relationship — only no linear relationship.
Association vs. independence (two-way tables)
Two variables are independent if the conditional distribution of one is the same across all categories of the other. If distributions differ, the variables are associated.

SAT strategy tips
Residual = actual − predicted (always this order)
Residual is always actual minus predicted, never the reverse. A positive residual means the actual value is above the line of best fit. A negative residual means it's below. The SAT tests this sign convention.
Check for association in two-way tables by comparing conditional distributions
If the row percentages are the same across all rows, the two variables are independent. If they differ, there is an association. Don't rely on the counts alone — always convert to percentages within each row or column.
r close to ±1 doesn't mean causation
A high correlation coefficient (|r| near 1) means strong linear association — not causation. This is the same correlation vs. causation principle from Lesson 4.11, applied to numerical context.
Nonlinear fit: look at the residual pattern
If a residual plot shows a curved or systematic pattern rather than random scatter, the linear model is inadequate. The SAT will show you two residual plots and ask which model is better — choose the one with random scatter around zero.

Residual plot context
A researcher fits a linear model to data about temperature (x) and ice cream sales (y). The residual plot shows residuals that are negative for low x, positive for middle x, and negative again for high x — forming a curve.
A systematic curved pattern in a residual plot means the linear model misses a real curved relationship in the data. The researcher should try a quadratic or other nonlinear model instead.
Question 3 · Residual Plot Interpretation
What does the curved pattern in the residual plot suggest?
AThe linear model is a good fit for the data.
BThe data has no association between temperature and sales.
CA nonlinear model would better describe the relationship.
DThe residuals confirm the linear model is appropriate.
Correct! A curved pattern in a residual plot means the linear model is systematically over- or under-predicting in different regions — there is structure the model isn't capturing. A nonlinear (e.g., quadratic) model would fit better. A good linear fit has residuals randomly scattered around zero with no visible pattern.
