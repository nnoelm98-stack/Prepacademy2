Systems of Equations
Apply substitution and elimination to messier coefficients and real-world word problems — the bread-and-butter of the SAT calculator section.

Method selection — with a calculator
With a calculator, elimination becomes even faster — you can multiply coefficients without worrying about arithmetic errors. Substitution is still best when one variable is already isolated.
Substitution — use when y = or x = appears
Solve one equation for one variable, substitute into the other, solve, back-substitute.
y = 3x − 7 and 2x + y = 11
→ 2x + (3x−7) = 11
→ 5x = 18 → x = 3.6
Elimination — use when both equations are Ax + By = C
Multiply to match coefficients. Add or subtract to eliminate one variable. Solve and back-substitute.
3x + 4y = 19 and 5x − 4y = 13
→ Add: 8x = 32 → x = 4
→ y = 7/4 = 1.75
One solution
Lines intersect. Different slopes.
No solution
Parallel lines. Same slope, different intercepts.
Infinite solutions
Same line. One equation is a multiple of the other.

SAT strategy tips
Write both equations before solving
In word problems, identify two separate conditions and write one equation for each before touching the calculator. Label your variables clearly: let x = [what] and y = [what].
Check both equations with your solution
After solving, substitute (x, y) into both original equations. If either one fails, there's an error. The calculator makes verification fast — always do it.
SAT often asks for x + y, not x or y alone
Read the question carefully. Many systems questions ask for a combination (x + y, 2x − y, etc.) rather than the individual values. You may be able to find the combination without fully solving the system.
No solution: same slope, different intercept
For a system to have no solution, write both equations in y = mx + b form. If slopes are equal but y-intercepts differ, no solution. The SAT tests this with parameter questions: "for what value of k does the system have no solution?"
