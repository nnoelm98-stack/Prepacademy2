Functions & Transformations
Master every transformation of a function — shifts, reflections, stretches, and compressions — and apply them to any function type: linear, quadratic, exponential, and absolute value.
13 min read3 practice questions+20 pts on completion
Complete transformation reference
TransformationEquationEffect on graph
f(x) + kk > 0Shifts UP by k units. Every y-value increases by k.
f(x) − kk > 0Shifts DOWN by k units. Every y-value decreases by k.

Worked example — combining transformations
The graph of y = f(x) passes through (2, 5). Find the corresponding point on y = −2f(x − 3) + 1.

Start with point (2, 5) on f(x).
f(x − 3): shift right 3 → x becomes 2 + 3 = 5
−2f(...): reflect and stretch → y becomes −2(5) = −10
+1: shift up 1 → y becomes −10 + 1 = −9
New point: (5, −9)
SAT strategy tips
Horizontal shifts are counterintuitive — always double-check
f(x + 3) shifts LEFT by 3, not right. f(x − 3) shifts RIGHT by 3. To remember: set the inside expression equal to zero — x + 3 = 0 means x = −3, so the shift is to the left. This counterintuitive direction is tested constantly.
Track a single point through combined transformations
For any combined transformation, pick the simplest point from the original graph and apply each transformation in order to that point. This is faster and more reliable than trying to interpret the combined formula all at once.
Vertical changes: affect y, apply outside the function
Anything added, subtracted, or multiplied OUTSIDE f(...) changes y. Anything inside f(...) changes x. Keep this rule clear: outside → vertical effect, inside → horizontal effect (often with opposite sign).
Absolute value transformation: |f(x)| reflects negative part
y = |f(x)| takes any part of the graph below the x-axis and reflects it above. Any y-value that was negative becomes positive. Parts already above the x-axis stay unchanged.
Practice questions
Problem
The graph of f(x) = x² has vertex at (0, 0). Consider:
g(x) = (x + 4)² − 6
f(x+4) shifts left 4: vertex moves from x=0 to x=−4. The −6 shifts down 6: vertex moves from y=0 to y=−6. New vertex: (−4, −6).
Question 1 · Vertex after Transformation
What is the vertex of g(x)?
A(4, −6)
B(−4, 6)
C(−4, −6)
D(4, 6)
Correct! (−4, −6)
(x+4)² = (x−(−4))² → shifts LEFT 4 → vertex x = −4
−6 outside → shifts DOWN 6 → vertex y = −6
Vertex: (−4, −6) ✓

Common trap: (x+4)² makes students think vertex is at x=+4. Set x+4=0 → x=−4.
Not quite. f(x+4) shifts the graph LEFT (set x+4=0 → x=−4). The −6 outside shifts DOWN. What does that make the vertex?
Left 4, down 6 → vertex (−4, −6)
Problem
The graph of y = f(x) passes through the point (−3, 8). Consider:
h(x) = −f(x) + 5
Apply transformations to the point (−3, 8). First −f(x): reflects y → y becomes −8. Then +5: shifts up 5 → y becomes −8+5 = −3. x-coordinate is unchanged by these vertical transformations.
Question 2 · Tracking a Point
What point must lie on the graph of h(x) = −f(x) + 5?
A(−3, 3)
B(3, −3)
C(−3, −3)
D(3, 13)
Correct! (−3, −3)
Original point: (−3, 8)
−f(x): y → −8 · (x stays −3)
+5: y → −8+5 = −3
New point: (−3, −3) ✓

Verify: h(−3) = −f(−3)+5 = −8+5 = −3 ✓
Not quite. Both −f(x) and +5 are outside the function, so they affect y only. x stays −3. Apply to y=8: first negate, then add 5.
y: 8 → −8 → −8+5 = −3 · Point: (−3, −3)
Problem
The function f(x) = 2ˣ is transformed to produce:
g(x) = 2^(x − 1) + 3
Horizontal shift: x−1 inside → shifts right 1. So the y-intercept of f (which was at x=0) moves to x=1. Vertical shift: +3 outside → shifts up 3. The horizontal asymptote of f (y=0) moves to y=3.
Question 3 · Exponential Transformation
What is the horizontal asymptote of g(x)?
Ay = 0
By = 1
Cy = 3
Dy = −1
Correct! y = 3
f(x) = 2ˣ has horizontal asymptote y = 0 (as x→−∞, 2ˣ→0)
g(x) = 2^(x−1) + 3: the +3 shifts the entire graph UP by 3
New asymptote: y = 0 + 3 = 3 ✓

The horizontal shift (x−1) moves the graph right but doesn't change the asymptote. Only the vertical shift (+3) changes the asymptote.
Not quite. The original f(x) = 2ˣ approaches y = 0 as x→−∞. Adding +3 outside shifts the entire graph up by 3 — including the asymptote. What does the asymptote become?
y = 0 + 3 = 3
