Systems of Inequalities
Master graphing systems of inequalities, identifying feasible regions, and solving linear programming problems — the optimization applications the SAT uses in its most complex word problems.
12 min read3 practice questions+20 pts on completion
Solving systems of inequalities
A system of inequalities has a solution region — all points (x, y) that satisfy every inequality simultaneously. On a graph, this is the area where all shaded regions overlap.
Step 1
Graph each boundary line
Write each inequality as an equation and graph it. Use a solid line for ≤ or ≥ (boundary included) and a dashed line for < or > (boundary excluded).
Step 2
Shade the correct half-plane
Test the point (0, 0) in each inequality. If it satisfies the inequality, shade the side containing (0, 0). If not, shade the other side.
Step 3
Find the overlap region
The solution is where ALL shaded regions overlap. Any point in this region satisfies every inequality in the system.
Step 4
Verify with a test point
Pick any point in your proposed solution region and substitute into all inequalities. Every single one must be satisfied. If any fails, recheck the shading.
Worked example — word problem setup
A baker makes cakes (c) and pies (p). Each cake takes 2 hours and each pie takes 3 hours. The baker has at most 24 hours. The baker must make at least 3 cakes. Write the system.

2c + 3p ≤ 24    (time constraint)
c ≥ 3    (minimum cakes)
c ≥ 0, p ≥ 0    (non-negative quantities)

To maximize total items (c + p), the optimal solution is at a corner of the feasible region.
SAT strategy tips
Test (0,0) first to determine shading direction
For any inequality, substitute x=0, y=0. If it's satisfied, shade the region containing the origin. If not, shade away from the origin. This quick test works for all linear inequalities except those where the boundary passes through the origin itself.
"At most" means ≤; "at least" means ≥
Translate key phrases: "at most X" → ≤ X. "At least X" → ≥ X. "No more than" → ≤. "No fewer than" / "minimum of" → ≥. Getting the direction of the inequality wrong changes the entire feasible region.
Verify proposed solutions by substituting
When the SAT asks "which point is in the solution region?", substitute each answer choice into all inequalities — don't try to visualize the graph. This substitution approach is faster and eliminates graphing errors.
Optimization: check corner points of the feasible region
The maximum or minimum of a linear objective function always occurs at a corner (vertex) of the feasible region. Find the corners by solving pairs of boundary equations as a system, then evaluate the objective function at each corner.

Problem

Write two inequalities: spending → 15t + 25h ≤ 150. Items → t + h ≥ 4. Non-negative: t ≥ 0, h ≥ 0. Then check which combination satisfies all constraints.

Problem
A system of inequalities has the feasible region bounded by three corners: (0, 6), (4, 2), and (0, 0). The objective is to maximize P = 3x + 5y.
Evaluate P = 3x + 5y at each corner point. The maximum value of a linear objective function always occurs at a corner of the feasible region.

At (0, 6): P = 0 + 30 = 30
