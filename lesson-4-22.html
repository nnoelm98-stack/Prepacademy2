Quadratic & Polynomial Applications

Real-world quadratic setups
Area and dimension problems
Express length and width in terms of one variable using a constraint, write the area as a product, set equal to a given area, and solve the resulting quadratic.
Rectangle: l = x+3, w = x. Area = 40
x(x+3) = 40 → x²+3x−40 = 0
(x+8)(x−5) = 0 → x = 5
Number relationship problems
Two numbers differ by some amount and their product is given. Let the numbers be x and (x + d), set their product equal to the given value, and solve.
Two consecutive even integers, product 80:
n(n+2) = 80 → n²+2n−80 = 0
(n+10)(n−8) = 0 → n = 8 (positive)
Discriminant — number of solutions
Discriminant Δ = b²−4ac determines how many real solutions exist. Δ > 0: two real solutions. Δ = 0: one solution (repeated). Δ < 0: no real solutions.
x²+kx+9 = 0 has one solution when:
k²−36 = 0 → k = ±6
Polynomial remainder theorem
If a polynomial p(x) is divided by (x − a), the remainder equals p(a). If p(a) = 0, then (x − a) is a factor. Use this to verify zeros or find missing coefficients.
p(x) = x³ − 2x + k. If (x−3) is a factor:
p(3) = 27−6+k = 0 → k = −21
Worked example — discriminant application
For what values of k does kx² − 6x + 3 = 0 have no real solutions?

Δ = (−6)² − 4(k)(3) = 36 − 12k
No real solutions when Δ < 0:
36 − 12k < 0 → 12k > 36 → k > 3
Also need k ≠ 0 (otherwise not quadratic). Answer: k > 3.
SAT strategy tips
Draw and label dimensions in area problems
Before writing any equation, sketch the shape and label both dimensions with expressions in one variable. This prevents misidentifying which dimension is length and which is width, and ensures the area equation is set up correctly.
Discriminant = b²−4ac, not (b²−4ac)/2a
The discriminant is just the expression under the square root in the quadratic formula: b²−4ac. You only divide by 2a when finding the actual roots. For questions about the number of solutions, compute b²−4ac and check its sign.
Remainder theorem: evaluate, don't divide
To find the remainder when p(x) is divided by (x−a), just compute p(a). This is always faster than performing polynomial long division. If the question asks whether (x−a) is a factor, check if p(a) = 0.
Reject negative solutions for lengths/times
When a quadratic gives two solutions, always check context. Lengths, times, counts, and prices must be non-negative. Reject any solution that's negative or doesn't make physical sense for the problem.

Problem
A rectangular garden has a length that is 5 meters more than its width. The area of the garden is 84 m².
Let width = w. Then length = w + 5. Area: w(w+5) = 84. Expand: w²+5w−84=0. Factor or use the quadratic formula. Reject the negative solution.

Correct! 7 meters
w(w+5) = 84
w²+5w−84 = 0
(w+12)(w−7) = 0
w = 7 or w = −12 (reject negative)
Width = 7 m · Length = 12 m
Check: 7 × 12 = 84 ✓

Problem
For the quadratic equation:
3x² + bx + 12 = 0
Find the value(s) of b for which the equation has exactly one real solution.
Exactly one solution means the discriminant = 0: b²−4(3)(12) = 0. Solve: b²−144=0 → b=±12.

Problem
The polynomial p(x) = x³ + 2x² − 5x + k is divisible by (x − 2) with no remainder.
By the remainder theorem, if (x−2) is a factor then p(2) = 0. Compute p(2): 8 + 8 − 10 + k = 0. Solve for k.
Question 3 · Remainder Theorem
What is the value of k?
Ak = −6
Bk = 6
Ck = −10
Dk = 2
Correct! k = −6
Remainder theorem: (x−2) is a factor → p(2) = 0
p(2) = 2³ + 2(2²) − 5(2) + k
= 8 + 8 − 10 + k = 6 + k
6 + k = 0 → k = −6 ✓
Not quite. By the remainder theorem, if (x−2) is a factor then p(2) = 0. Evaluate p(2) = 8 + 8 − 10 + k and set equal to zero.
6 + k = 0 → k = −6
