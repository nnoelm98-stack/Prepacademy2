Quadratic Functions
Apply quadratic skills from Module 3 to complex real-world contexts — projectile motion, revenue models, and area problems — where the calculator handles messy arithmetic so you can focus on setup and interpretation.
13 min read3 practice questions+20 pts on completion
Three forms — quick reference
Standard form
ax² + bx + c
y-intercept = c directly. Use quadratic formula to find roots. Axis of symmetry: x = −b/(2a).
Vertex form
a(x − h)² + k
Vertex = (h, k) directly. Min/max value = k. Axis = x = h. Best for max/min questions.
Factored form
a(x − r₁)(x − r₂)
Roots = r₁ and r₂ directly. Best for x-intercept questions. Axis of symmetry: x = (r₁ + r₂)/2.
Worked example — projectile motion
A ball is launched from a platform. Its height (feet) after t seconds is h(t) = −16t² + 48t + 64.

Maximum height:
t at vertex = −48/(2×−16) = −48/−32 = 1.5 seconds
h(1.5) = −16(2.25) + 48(1.5) + 64 = −36 + 72 + 64 = 100 feet

When does it hit the ground? Set h = 0:
−16t² + 48t + 64 = 0 → t² − 3t − 4 = 0 → (t−4)(t+1) = 0
t = 4 seconds (reject t = −1)
SAT strategy tips
Choose the form that answers the question
Max/min questions → convert to vertex form. Root/x-intercept questions → factor or use quadratic formula. y-intercept questions → read c from standard form. Don't convert unless you need to.
Revenue models: R = price × quantity
Many calculator-section quadratics are revenue models: R(x) = (base price − decrease·x)(base quantity + increase·x). Expand and maximize. These always produce a parabola opening downward.
Use the calculator for the quadratic formula
With a calculator, plug a, b, c directly into x = (−b ± √(b²−4ac))/(2a). Compute the discriminant first (b²−4ac), then the two roots. No need to factor if the numbers are messy.
Check: does the answer make physical sense?
In projectile problems, time must be positive and height must be between launch height and maximum. If your answer gives a negative time or height above maximum, recheck the setup.
Practice questions
Problem
The height of a rocket (in meters) t seconds after launch is:
h(t) = −5t² + 40t + 15
Maximum height occurs at the vertex. Find t at vertex: t = −40/(2×−5) = 4 seconds. Then compute h(4).
Question 1 · Maximum Height
What is the maximum height the rocket reaches?
A75 meters
B95 meters
C100 meters
D115 meters
Correct! 95 meters
t_vertex = −40/(2×−5) = 4 seconds
h(4) = −5(16) + 40(4) + 15
= −80 + 160 + 15
= 95 meters ✓
Not quite. Maximum height is at the vertex. Find t: −b/(2a) = −40/(2×−5) = 4. Then evaluate h(4).
h(4) = −80+160+15 = 95 meters
Problem
A company sells widgets. If they charge p dollars per widget, their weekly revenue (in dollars) is:
R(p) = −20p² + 800p
Revenue is maximized at the vertex. Since this is in the form ap² + bp, use p = −b/(2a) = −800/(2×−20) = 20 to find the optimal price.
Question 2 · Revenue Optimization
What price per widget maximizes revenue, and what is that maximum revenue?
A$20 per widget; maximum revenue $8,000
B$40 per widget; maximum revenue $16,000
C$20 per widget; maximum revenue $16,000
D$10 per widget; maximum revenue $7,000
Correct!
Vertex at p = −800/(2×−20) = 20
R(20) = −20(400) + 800(20)
= −8,000 + 16,000 = $8,000
Price: $20 · Max revenue: $8,000 → Answer A ✓
Not quite. Find the vertex: p = −800/(2×−20) = 20. That's the optimal price. Then compute R(20) for the maximum revenue.
R(20) = −20(400)+800(20) = $8,000
Problem
A quadratic function has roots at x = −2 and x = 5, and passes through the point (0, −20).
Use factored form: f(x) = a(x+2)(x−5). Substitute the point (0, −20) to find a: −20 = a(2)(−5) = −10a → a = 2.
