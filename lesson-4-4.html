Exponential Growth & Decay
Apply exponential models to compound interest, population growth, radioactive decay, and depreciation — the real-world contexts the SAT uses in the calculator section.
13 min read3 practice questions+20 pts on completion
Key exponential formulas for the SAT
f(t) = a · bᵗ    [basic exponential]
A = P(1 + r/n)ⁿᵗ    [compound interest]
A = Pe^(rt)    [continuous compounding]
f(t) = a · (1/2)^(t/h)    [half-life]
a = initial value · r = rate · n = compoundings per year · t = time · h = half-life period
ContextModelKey interpretation
Compound interestA = P(1 + r/n)ⁿᵗP = principal, r = annual rate (decimal), n = times compounded per year, t = years
Annual growth/decayf(t) = a·bᵗb = 1+r for growth, b = 1−r for decay. t = number of years.
Half-lifef(t) = a·(0.5)^(t/h)After each half-life h, half the substance remains. t/h = number of half-lives elapsed.
Doubling timef(t) = a·2^(t/d)After each doubling period d, quantity doubles. t/d = number of doubling periods.
Worked example — compound interest
$5,000 is invested at 4.8% annual interest compounded monthly. What is the value after 6 years?

A = P(1 + r/n)ⁿᵗ
= 5000(1 + 0.048/12)^(12×6)
= 5000(1.004)^72
= 5000 × 1.3385 ≈ $6,692.60

Use calculator: 5000 × (1.004)^72 = $6,692.61
SAT strategy tips
Identify the model before using the calculator
Write the formula with all values substituted before touching the calculator. Compound interest has 4 parameters (P, r, n, t) — label each from the problem before computing.
Half-life: count periods, not raw time
For half-life problems, compute t/h (number of half-life periods elapsed) as the exponent. If half-life is 5 years and t = 20 years: 20/5 = 4 half-lives → remaining fraction = (1/2)⁴ = 1/16.
Annual vs. monthly vs. continuous
Annual compounding: n = 1. Monthly: n = 12. Daily: n = 365. Continuous: A = Peʳᵗ. More frequent compounding always yields slightly more — but the difference diminishes as n increases.
Build the model from context clues
"Grows by 7% each year" → b = 1.07. "Loses 15% of its value per year" → b = 0.85. "Population doubles every 8 years" → f(t) = a·2^(t/8). Always extract b from the rate before evaluating.
Practice questions
Problem
A radioactive substance has a half-life of 12 years. A sample currently contains 480 grams.
After each 12-year half-life, half the substance remains. In 36 years, there are 36/12 = 3 half-lives. Multiply by (1/2) three times: 480 × (1/2)³.
Question 1 · Half-Life
How many grams will remain after 36 years?
A120 grams
B60 grams
C40 grams
D30 grams
Correct! 60 grams
Half-lives elapsed: 36/12 = 3
Remaining: 480 × (1/2)³ = 480 × 1/8 = 60 grams ✓

Or step by step:
After 12 yr: 240g · After 24 yr: 120g · After 36 yr: 60g ✓
Not quite. Count half-life periods: 36 ÷ 12 = 3 periods. Each period halves the amount: 480 × (1/2)³.
480 × 1/8 = 60 grams

Quarterly compounding: n = 4, r = 0.06. Substitute t = 5 years. Use calculator: 8000 × (1.015)^20.

Problem

Model: P(t) = 120,000 · (1.025)^t where t = years after 2010. For 2025: t = 15. Use calculator to evaluate.
