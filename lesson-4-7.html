SOH-CAH-TOA — the three ratios
For a right triangle with a reference angle θ, the three trigonometric ratios relate the angle to the sides of the triangle. Always label: opposite (side across from θ), adjacent (side next to θ, not hypotenuse), and hypotenuse (longest side, across from 90°).
SOH
sin θ = opp/hyp
Sine = Opposite over Hypotenuse
CAH
cos θ = adj/hyp
Cosine = Adjacent over Hypotenuse
TOA
tan θ = opp/adj
Tangent = Opposite over Adjacent
Key identities and relationships
Complementary angle identity ← most tested
sin θ = cos(90° − θ)
cos θ = sin(90° − θ)
In a right triangle, if one acute angle is θ, the other is (90°−θ). The sine of one equals the cosine of the other. The SAT uses this constantly.
Pythagorean identity
sin²θ + cos²θ = 1
Always true for any angle. Useful for finding sin given cos (or vice versa) without finding the angle itself.
Tangent identity
tan θ = sin θ / cos θ
Tangent equals opposite/adjacent, which equals (opp/hyp) ÷ (adj/hyp) = sin/cos.
Reciprocal relationships
1/sin θ = csc θ
1/cos θ = sec θ
1/tan θ = cot θ
The SAT rarely tests these directly, but recognizing them helps simplify expressions.
Worked example — complementary angles
In a right triangle, sin(x°) = 4/5. What is cos(90° − x°)?

By the complementary angle identity: cos(90° − x°) = sin(x°)
Therefore cos(90° − x°) = 4/5

No calculation needed — just recognize the identity. This is the most common trig question format on the SAT.
Worked example — finding a side using trig
A ladder leans against a wall, making a 65° angle with the ground. The ladder is 10 meters long. How high up the wall does it reach?

The height is opposite to 65°; the ladder (10m) is the hypotenuse.
sin(65°) = opposite/hypotenuse = h/10
h = 10 × sin(65°) ≈ 10 × 0.906 ≈ 9.06 meters
SAT strategy tips
Label sides before writing ratios
Before using SOH-CAH-TOA, always label which side is opposite, adjacent, and the hypotenuse relative to your reference angle θ. Mislabeling is the most common trig error.
sin(x) = cos(90−x) is on every SAT
The SAT always tests the complementary angle relationship. If sin(A) = cos(B), then A + B = 90°. If sin(x°) = cos(32°), then x + 32 = 90, so x = 58. This takes 5 seconds once you know it.
Use the calculator correctly for trig
Make sure your calculator is in DEGREE mode (not radian) for SAT problems. To find an angle: use inverse trig — sin⁻¹, cos⁻¹, tan⁻¹. To find a side: use the ratio directly.
Trig with the Pythagorean identity
If sin θ = 3/5, find cos θ: sin²θ + cos²θ = 1 → 9/25 + cos²θ = 1 → cos²θ = 16/25 → cos θ = 4/5. This avoids finding the angle — just work with the ratios directly.

Problem
In a right triangle, cos(x°) = 5/13.
Use the complementary angle identity: sin(90° − x°) = cos(x°). The sine of the complementary angle equals the cosine of the original angle — no calculation required.

cos(x°) = 5/13

Problem
A surveyor stands 80 meters from the base of a building and measures the angle of elevation to the top to be 38°.
The height is opposite the 38° angle; the horizontal distance (80 m) is adjacent. Use tan(38°) = opposite/adjacent = height/80. Solve: height = 80 × tan(38°).

Problem
In a right triangle, sin(θ) = 7/25.
Use the Pythagorean identity: sin²θ + cos²θ = 1. Substitute sin θ = 7/25, solve for cos θ. Then use tan θ = sin θ / cos θ.
Question 3 · Pythagorean Identity
What is the value of tan(θ)?
A7/24
B24/25
C7/25
D25/7
Correct! tan θ = 7/24
sin²θ + cos²θ = 1
(7/25)² + cos²θ = 1
49/625 + cos²θ = 1
cos²θ = 576/625 → cos θ = 24/25

tan θ = sin θ/cos θ = (7/25)/(24/25) = 7/24 ✓

Or: 7-24-25 is a Pythagorean triple!
sin=7/25 → opposite=7, hyp=25 → adjacent=24
tan = 7/24 ✓
Not quite. Use sin²θ + cos²θ = 1 to find cos θ. Then tan θ = sin θ / cos θ. Alternatively, recognize 7-24-25 as a Pythagorean triple.
cos θ = 24/25 · tan θ = 7/24
